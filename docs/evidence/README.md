# Результати перевірок системи моніторингу

У цьому каталозі зібрано результати перевірок бази даних, вебінтерфейсу та передавання показників із ESP8266.

## Зміст матеріалів

| Файли | Зміст |

| `02`–`03` | Поточний стан каналів і статистика вимірювань |
| `04`–`07` | Перевірки фізичних меж, обмежень UNIQUE, FOREIGN KEY і CHECK |
| `08`–`12` | Історія відхилень, правила контролю, робота тригерів і аудит змін |
| `13`–`14` | Права ролей та налаштування RLS |
| `15`–`18` | Плани виконання запитів і агрегування історії вимірювань |

| `21`–`23` | Перевірка відновленої резервної копії PostgreSQL |

| `26a`–`26b` | Зчитування показників ESP8266 і пакетне передавання до Supabase |

У файлі [`evidence_index.csv`](evidence_index.csv) наведено перелік зображень із коротким описом результатів. Каталог [`additional/`](additional/) містить додаткові зображення вебінтерфейсу та SQL-перевірок.

## Основні результати

- Реалізовано дев'ять таблиць, два представлення і три тригери PostgreSQL.
- Перевірено обмеження цілісності, автоматичне створення й закриття відхилень та аудит правил.
- Продемонстровано блокування рядка у двох незалежних транзакціях.
- Перевірено відновлення бази з резервної копії, яка містила 34 613 вимірювань.
- Отримано успішну відповідь сервера на пакет із 24 показників ESP8266 (`HTTP 200`).
